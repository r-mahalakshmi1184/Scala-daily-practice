# Day 21 – Spark Catalog

## Overview

This practice focuses on Spark Catalog operations and managing databases, tables, views, and metadata using Spark SQL.

## Objectives

- List databases
- List tables
- Create temporary views
- Register and query tables
- Inspect table metadata
- Inspect schema information

## Scenario

Build a small analytics database for hotel booking data.

The data can be registered as tables or temporary views and queried using Spark SQL.

## Key Concepts

- Spark Catalog
- Databases
- Tables
- Temporary Views
- Table Registration
- Schema Metadata
- Spark SQL

## Learning Outcome

Learned how Spark Catalog provides information about databases, tables, views, and schemas and how Spark SQL can be used to query registered data.

## Technologies

- Scala
- Apache Spark
- Spark SQL
- SBT
